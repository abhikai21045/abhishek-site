## Publishing a new writeup 

1. Add a Markdown file to `writeups/`, e.g. `writeups/vulnhub_lab1.md`
2. Add one entry to `writeups/manifest.json`:

   ```json
   {
     "slug": "Vulnhub_lab1",
     "title": "Vulnhub lab - Network CTF",
     "date": "2026-09-12",
     "tags": ["Network", "CTF"],
     "difficulty": "Medium",
     "summary": "Some summary that you can think of"
   }
   ```

3. Commit and push.
